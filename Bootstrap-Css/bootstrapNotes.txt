
How to Add Bootstrap to a Project

Bootstrap is added to a project by including its CSS and JavaScript files, either through a CDN (Content Delivery Network) or by downloading the files locally.


    <!-- Bootstrap CSS -->
    <link
        href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css"
        rel="stylesheet">

    <!-- Bootstrap JavaScript -->
    <script
        src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js">
    </script>

Bootstrap Classes
A Bootstrap class is a predefined CSS class that applies specific styles or behaviors to an HTML element.

<button class="btn btn-primary">Click Me</button>

btn → Gives the element basic Bootstrap button styling.
btn-primary → Makes it use Bootstrap's primary (blue) button style.

Bootstrap Color Names
| Class           | Color      | Meaning                   |
| --------------- | ---------- | ------------------------- |
| `btn-primary`   | Blue       | Main action               |
| `btn-secondary` | Gray       | Secondary action          |
| `btn-success`   | Green      | Success / Save            |
| `btn-danger`    | Red        | Delete / Remove / Warning |
| `btn-warning`   | Yellow     | Caution                   |
| `btn-info`      | Light Blue | Information               |
| `btn-dark`      | Black      | Dark theme                |
| `btn-light`     | White      | Light theme               |

Bootstrap Container

A Bootstrap container is a layout wrapper that provides horizontal padding and controls the width of the content, helping align and organize the page.




container → Controls the page width.
row → Creates a horizontal row.
col-md-6 → Makes two equal columns on medium and larger screens.

There are actually 3 types of containers in Bootstrap:
| Class                    | Width                                         |
| ------------------------ | --------------------------------------------- |
| `container`              | Fixed max-width (changes at breakpoints)      |
| `container-fluid`        | Always 100% width                             |
| `container-{breakpoint}` | Fluid until a specific breakpoint, then fixed |

Breakpoint
A breakpoint is a predefined screen width at which Bootstrap changes the layout to make the website responsive.

| Prefix     | Screen Size       | Meaning                         |
| ---------- | ----------------- | ------------------------------- |
| `col-`     | Extra Small       | Applies to **all** screen sizes |

| `col-lg-`  | Large             | Large screens and larger        |
| `col-xl-`  | Extra Large       | Extra-large screens and larger  |
| `col-xxl-` | Extra Extra Large | Very large screens and larger   |

What is a row?

A Bootstrap row is a Flexbox container that arranges Bootstrap columns (col-*) horizontally and manages their alignment and spacing.

A row is simply a horizontal container for columns.

Every part has a job:

container → Controls the page width.
row → Controls the horizontal layout.
col → Controls how much space an item occupies.

----------------------------------------------------------------------------
----------------------------------------------------------------------------
What is a col?

col is a Bootstrap column class that automatically divides the available space equally among all columns within a row.
<div class="col-6"> || This column must occupy 6 out of 12 columns.

if we directly use col - Bootstrap decide with equally
| Class      | Meaning                                           |
| ---------- | ------------------------------------------------- |
| `col`      | Automatically divide the available space equally. |
| `col-6`    | Always occupy 6 of the 12 columns.                |
| `col-md-6` | Occupy 6 columns from the `md` breakpoint onward. |

| `g-3` |   1rem = **16px** |

What is d-flex ?

d-flex is a Bootstrap utility class that applies display: flex to an element, making it a Flexbox container.
----------------------------------------------------------------------------


justify-content-* is a Bootstrap Flexbox utility that controls the horizontal alignment and distribution of flex items along the main axis.

| Class                     | Start Edge      | Between Items | End Edge        |
| ------------------------- | --------------- | ------------- | --------------- |
| `justify-content-between` | ❌ No space      | ✅ Equal       | ❌ No space      |
| `justify-content-around`  | ✅ Half-size gap | ✅ Equal       | ✅ Half-size gap |
| `justify-content-evenly`  | ✅ Equal gap     | ✅ Equal       | ✅ Equal         |

----------------------------------------------------------------------------
align-items-* is a Bootstrap Flexbox utility that controls the alignment of flex items along the cross axis (vertical axis when flex-direction: row).


align-items-start → Person stands at the top.
align-items-center → Person stands in the middle.
align-items-end → Person stands at the bottom.


----------------------------------------------------------------------------
flex-row is a Bootstrap Flexbox utility that arranges flex items horizontally from left to right by applying flex-direction: row.

flex-column is a Bootstrap Flexbox utility that changes the flex direction from horizontal (row) to vertical (column) by applying flex-direction: column.

| `flex-direction`  | Main Axis  | Cross Axis | `justify-content` | `align-items` |
| ----------------- | ---------- | ---------- | ----------------- | ------------- |
| `row` *(default)* | Horizontal | Vertical   | Left ↔ Right      | Top ↕ Bottom  |
| `column`          | Vertical   | Horizontal | Top ↕ Bottom      | Left ↔ Right  |


----------------------------------------------------------------------------
flex-wrap is a Bootstrap Flexbox utility that allows flex items to move onto the next line when there isn't enough space in the container.

Bootstrap Button Variants (btn-*)

Button variants are predefined Bootstrap classes that change the appearance (color and styling) of a button to represent different purposes or actions.

Outline Buttons (btn-outline-*)
Outline button variants are Bootstrap button styles that display a colored border and text instead of a filled background. The background becomes colored when the user hovers over the button.


----------------------------------------------------------------------------
Full-Width Buttons (w-100)

w-100 is a Bootstrap width utility that makes an element occupy 100% of its parent's available width.

disabled in button
| Feature               | HTML                 | Bootstrap                        |
| --------------------- | -------------------- | -------------------------------- |
| Disable functionality | `disabled` attribute | Uses HTML's `disabled`           |
| Disabled appearance   | Browser default      | Bootstrap styles it consistently |


----------------------------------------------------------------------------
Button Groups (btn-group)
btn-group is a Bootstrap component that combines multiple buttons into a single horizontal group so they appear connected and behave as one visual unit.

btn-group is applied to the parent, not the buttons.
<div class="btn-group">
    <button class="btn btn-primary">A</button>
    <button class="btn btn-primary">B</button>
</div>2
